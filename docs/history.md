### 매매 점수(1~5점) 기능
- `Trade`/`CoinTrade`에 `tradeScore Int?` 필드 추가, 매도 완료된 거래에만 입력 활성화 (주식/코인 동일)
- 저장 시 수익률 +2% 초과면 4점, 손실 -5% 이내면 2점을 자동 선택, 그 외 구간은 3점 기본값 — 언제든 수동으로 덮어쓰기 가능
- 카드형 뷰(`TradeCard`)에 점수 표시

### 매매 계획(보유기간) 및 목표가/손절가 자동 계산 (PR #65)
- `Trade`/`CoinTrade`에 `plannedHoldingPeriod`(1일/1주일/1달/6개월이내/6개월이상) 필드 추가
- 계획 대비 실제 보유일수를 비교해 목록에 초과/이내 배지 표시 (보유중이어도 계획 기간을 넘기면 즉시 표시)
- 거래 입력 시 계획을 고르면 매수 평균단가 기준 목표가/손절가를 자동 계산해 채움 (직접 수정하면 유지, "재계산" 링크로 복원)
- 거래 상세 차트에 목표가/손절가 라인 표시

### 복기 페이지 개선 (PR #66)
- 주식/코인 목록에 "계획 없음" 필터, 복기(타임라인) 페이지에 매매 계획 필터 체크박스 추가
- 복기 페이지 기본 보기를 월별 → 주별로 변경, 컬럼 기준을 "오늘"이 아닌 "실제 마지막 거래 시점"으로 변경해 빈 컬럼이 뜨지 않도록 수정
- 복기 페이지에서 삭제 버튼 제거, 계획 없는 거래의 수정 버튼에 배경색 표시
- 거래 수정 모달 폭 확장 + 매도/매수 내역 좌우 2열 배치

### 보유 종목 현재가 연동 및 손실 회복 계산기 (PR #67)
- 같은 서버의 파이썬 현재가 API를 프록시하는 `/api/stock-price` 추가 (로컬은 `localhost:5000`, 운영은 `localhost/upbit/...`)
- "현재가 새로고침" 버튼으로 보유 종목 요약 표 + 계좌별 카드에 실시간 평가손익 표시
- 상세 차트: 평균가 가로선을 오늘 날짜의 점(다이아몬드)으로 변경, 현재가도 있으면 점(별)으로 같이 표시
- 손실 회복 계산기: 목표 손실률까지 필요한 소액 매매 횟수를 계산하고, 실제 기록된 매도 횟수와 비교해 진행률 표시
- 자세한 내용은 [feature-current-price-recovery.md](./feature-current-price-recovery.md) 참고
